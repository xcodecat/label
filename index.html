SETTINGS

Settings

◆ Developer

Unlocked from the logo. Diagnostics below; more tools will land here as they're built.

Mic debug logging

Writes one compact row per mic session to the Sheet's Errors tab (each line starts with MIC) so voice problems can be traced. Users never see it. On by default.

Restock counters

Shows item count, claimed count and sync status across the top of the Restock board. It hides on its own while you're typing an item.

Appearance

Weights are always stored in kilograms — changing this converts what you see, it never rewrites a saved list.

Export

Download CSV

Get a .csv file of all items, then import it in Google Sheets with File → Import. Images are not included in the CSV.

Backup & restore

Save a full backup of everything on this phone — items, PLU list, database cache and settings — as a file, or restore from one. Do this before reinstalling or moving to a new phone.

Sync to Google Sheets

Sends new items — including the barcode photo — straight into your spreadsheet. Paste the setup link below; Faisal has it.

PLU & barcode database

Keeps a PLU DB and Barcode DB tab in your Sheet. Edit names, country of origin and unit (ea/kg/lb/gm) there, then Pull to bring the changes into the app. Adding items on the Add tab also grows the Barcode DB.

Restock routing (developer)

Teach which table each product belongs on, walking your PLU DB one item at a time. Taught items always file where you put them, on every phone.

Store assortment (developer)

Mark what your store actually carries. Not-carried items are skipped on restock, and the trainer only walks what's in store — faster and more accurate. Search to add an item if you start carrying it later.

Restock location prompt

When the planogram shows an item on a pod or endcap, ask which location to file it under. Off just files it to its usual table.

This phone

Anything you add is kept and sent once this phone is approved. Nothing is lost while you wait.

Claims

"Send it" mails from your own Gmail through your Apps Script — same permission you already granted it, no password stored here.

Voice corrections

Every name you fix after speaking is remembered, so the same mishearing gets it right next time. 0 learned so far.

PLU database

Paste your list below — one per line. It reads 4011 Banana, 4011, Banana or Banana = 4011. Importing replaces the whole list.

Danger zone

Everything is stored only on this phone until you sync or export.
